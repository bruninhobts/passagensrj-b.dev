## 🇧🇷 Português

> **Plataforma de E-Commerce Regional e Checkout Otimizado para Passagens Rodoviárias**

Portal regional de vendas rápido e otimizado para busca e reserva de passagens de ônibus interestaduais, com foco em conversão mobile.

### 🚀 Principais Funcionalidades
- **Mapa de Assentos**: Seleção visual de poltronas do ônibus em tempo real e de forma dinâmica.
- **Checkout Mobile Otimizado**: Carregamento abaixo de 1.2s e fluxo reduzido focado em dispositivos móveis.
- **Emissão Automatizada**: Conexões assíncronas geram e enviam o voucher PDF imediatamente pós-pagamento.
- **Roteamento Dinâmico**: Mecanismo de conexões inteligentes de rotas rodoviárias para destinos regionais.

### 🛠️ Tecnologias
- **Stack**: Next.js, React, Node.js, Express, PostgreSQL.
- **Integrações**: Pix API, gateways de checkout seguro.

## 🇺🇸 English

> **Regional Coach E-Commerce & High-Conversion Checkout**

Fast e-commerce portal optimized for regional interstate bus ticketing.

### 🚀 Key Features
- **Interactive Seat Mapping**: Live seat map rendering for dynamic seat booking.
- **High-Conversion Mobile Checkout**: Fast mobile flow with <1.2s page loads.
- **Automated E-Ticket Delivery**: Asynchronous API hooks that generate and email PDF tickets instantly.
- **Dynamic Routing**: System that calculates multi-segment routes to regional destinations.

### 🛠️ Tech Stack
- **Stack**: Next.js, React, Node.js, Express, PostgreSQL.
- **Integrations**: Pix API, secure checkout gateways.
